# 电脑 VPN：Windows / Mac 怎么选、系统代理与 TUN 怎么设

电脑vpn的设置需要区分系统代理、TUN 虚拟网卡与浏览器扩展，不能用同一个开关解释全部接法。查电脑免费vpn、电脑梯子、电脑加速器或电脑翻墙时，先把需要处理的程序与官方说明对应起来，再核对 Windows 或 Mac 的平台要求。

## 系统代理靠程序读取操作系统的设置

Clash Verge Rev 文档对系统代理的描述，是通过界面开关改变操作系统的代理设置。名词解释又补充，这种方式依赖应用读取系统约定，并且不能代理 UDP 数据。它说的是这一接入方式怎样工作，不能把界面显示“开启”理解为所有程序都会使用同一路径。

快速入门把导入配置、选择节点及模式、打开代理列为不同步骤。导入解决配置进入客户端的问题，打开代理解决系统设置的问题。即使这些动作出现在同一窗口，也没有理由把配置导入成功当作后续每一步都已完成。

v2rayN 的系统代理说明则列出清除、自动配置、不改变及 PAC 模式，其中 PAC 标为 Windows。阅读时可以保留这些模式名，把它们与具体操作系统对应。不能因为另一个客户端有相似按钮，就把它的选项数量和行为原封搬过来。

对 Windows，v2rayN FAQ 解释自动配置系统代理只配置 HTTP。这个说明并不是在否认客户端的本地混合监听能力；系统设置与本地监听是不同层面。原项目入口以 [v2rayN 官方发布页](https://github.com/2dust/v2rayN/releases) 标记，Verge 的设置解释见 [Clash Verge Rev 官方文档站](https://clash-verge-rev.github.io/)。

## TUN 从虚拟网络接口接收数据

Verge 文档把 TUN 写成在系统中建立虚拟网卡，用于接管不读取系统代理的程序。其名词解释将 TCP、UDP 都列入 TUN 处理范围。这个描述可以说明它与系统代理的接口差异，但不构成对某个程序连接结果的承诺。

mihomo 的入站文档也把 HTTP、SOCKS、Mixed 归在应用代理一组，把 Redirect、TProxy、TUN 放在透明代理及系统捕获一组。这里使用的是文档分类，不把它扩展为所有产品通用的界面布局。具体客户端怎样提供开关，还要看客户端自己的说明。

服务模式又是另一个概念。Verge 安装并启动服务后，由服务进程拉起内核，文档给出的用途包括以非管理员身份启动 TUN。服务进程独立于界面，退出界面后仍可能留在后台；因此，关闭窗口与停止相关后台进程不是文档里的同义操作。

服务、内核和虚拟网卡三个词各自对应一层资料。核对时可以分别记录谁负责启动内核、当前选择什么模式、应用从哪个接口交出数据。这样保留了文档原有关系，也不会把“装了服务”写成“所有连接已经进入 TUN”。

## TUN 默认栈的两处表述要同时保留

Verge 的文档写 TUN 默认堆栈为 GVisor。mihomo 的英文 TUN 页则把默认值写作 mips；该页还列出 system、gvisor、mixed、mips 等取值。这两处都是文档当时的文字，不能删去其中一边再合成唯一答案。

截至 2026-10-22，官方页面显示 Verge 文档的默认项为 GVisor，而 mihomo TUN 文档写默认 mips，以官方页面为准。这里并列的是两个来源，不替它们判断实际安装后的默认配置。对应的内核资料入口是 [mihomo 官方文档站](https://wiki.metacubex.one/)。

关于 mixed，mihomo 文档解释 TCP 交由 system、UDP 交由 gvisor。这个说明能够用来阅读协议栈选项，却不足以推出哪个选项对所有电脑更合适。文档没有给出的应用级表现，本页不以名称或技术栈补写。

Verge 文档同时提到防火墙对内核程序的放行要求。这里不把关闭系统防火墙列成通用步骤，也不把另一份内核文档的设置照搬到客户端。操作系统设置、客户端预设和内核参数必须保留各自的出处。

## 浏览器扩展入口不能替代整机范围说明

Proton VPN 页面列有 Chrome 与 Firefox，Windscribe 页面也列出 Chrome、Firefox、MS Edge，TunnelBear 定价页则列有 Browser。它们可以确认官方页面存在浏览器相关入口。入口名称不是一份关于电脑全部网络请求范围的定义。

现有页面没有提供可供本页转述的完整扩展作用范围说明。因此这里只把它作为与桌面应用分开的入口，不宣称它会接管所有程序，也不补写它与系统代理开关的联动方式。浏览器外程序怎样联网，不能用扩展已安装这一项来代答。

这个边界也适用于平台名称。产品页面同时写 Windows 与 Chrome，不等于两者属于同一个安装包；写 Browser，也不允许替页面补齐所有浏览器名字。比较时按页面给出的项目逐项记下，缺少定义的地方保留缺口。

| 接法 | 本页取得的定义或范围 | 不能由此推出 |
| --- | --- | --- |
| 系统代理 | 应用读取操作系统代理设置 | 全部程序均采用该设置 |
| TUN | 虚拟网络接口处理连接 | 任意程序一定可达 |
| 浏览器扩展 | 产品页存在浏览器入口 | 整台电脑的通信均被接管 |

相关阅读分别用 [Proton VPN 免费版官方页面](https://protonvpn.com/free-vpn)、[Windscribe 官方页面](https://windscribe.com/)、[TunnelBear 官方页面](https://www.tunnelbear.com/) 指代。这里没有对扩展作统一技术定义，表格也不提供效果次序。

## Windows 与 Mac 的安装要求按项目分别核对

Verge 的 README 写支持 macOS 11 及以上，文档安装页写 macOS 12 及以上，并对 macOS 11 用户另有内核处理说明。这两种门槛在材料中并存，不能只选较低的一项放进兼容性表。对 Windows，安装文档还写明当前版本不再支持 Windows 7。

截至 2026-10-22，官方页面显示 Clash Verge Rev 的版本是 v2.5.8，README 的 Windows 架构写 x64、x86，而该版本安装资产列出 x64、arm64，以官方页面为准。平台支持文字与当期资产不是同一份清单，核对架构时要保留这层区别。版本入口为 [Clash Verge Rev 官方发布页](https://github.com/clash-verge-rev/clash-verge-rev/releases)。

FlClash 的桌面介绍列出 Windows 安装版及便携版，macOS 提供 DMG；它也列有桌面托盘菜单、全局快捷键。v2rayN 则把 Windows 发布包列为 ZIP，macOS 有 DMG、ZIP。安装包形态只能对应各自项目，不能据一个项目的扩展名替另一个项目找文件。

v2rayN 的发布文件说明要求 Windows 10 及以上、macOS 13.6 及以上。它对 ZIP 的解释是数据保存在解压目录，而非 ZIP 形态属于安装版。有关 FlClash 的发布资料由 [FlClash 官方发布页](https://github.com/chen08209/FlClash/releases) 表示，本页不提供安装包地址或替代下载渠道。

## 免费档的额度与电脑接法是不同问题

Proton VPN 的免费页称没有数据与速度上限，定价页又把免费速度描述为 Medium。这两个表达都保留：没有上限与页面采用的速度档位描述不能被压成“保证速度”。免费页还写同时连接一台设备，所列国家随机分配。

Windscribe 的首页把确认邮箱与免费月度额度联系在一起，TunnelBear 的免费链接也写有月度数据额度。这里不靠免费二字推断某种接法一定可用，也不把额度换算成可使用多久。额度、设备数量与应用接管范围回答不同问题。

免费软件的“免费”还需要与远端服务范围分开。Verge 快速入门把导入订阅或配置列为使用步骤；v2rayN 已读到的说明页没有承诺提供节点或订阅服务。本页只保留这些页面能确认的范围，不为未写出的资源作保证。

如果读者准备的是本地配置文件，阅读重点是客户端怎样导入；如果读者关心免费方案，阅读重点是该方案自己的限制。两项都可以出现在电脑使用流程中，但不能互相替代。安装界面出现某个按钮，并不会自动填好服务条款里的空白。

## 把配置导入、路由与系统接入分别记录

Verge 的规则、全局、直连三种模式在文档中各有含义。在规则模式下，出口由配置的匹配条件决定，全局模式使用手工选定的节点，直连则走本地网络。这是在描述出口选择，不能与系统代理、TUN 这类接入方式混成一组选项。

v2rayN 的界面说明另有从剪贴板解析配置的流程，遇到不同格式会按说明处理。解析功能与系统代理菜单并列存在，不表示解析器可以替代路由设置。把“数据已导入”与“程序按什么路径交出连接”分别记录，能让配置阅读保持具体。

桌面客户端还可能列有日志、请求或连接查看入口。FlClash 的功能表就包含这些项目，但这些条目只确认界面具有相应查看能力。它们不直接提供某个电脑故障的原因，本页也不按单个状态推断原因。

一个可复查的记录至少应说明操作系统、客户端名称、配置输入类型及接入模式。这是对本文各部分的阅读整理，不是新增的配置参数。信息齐全之后，仍以对应项目的页面为解释范围，不在不同项目之间替换默认值。

导入细节也能体现这种分层。Verge 文档的本地文件导入会把选中的文件复制到 profiles 目录，原文件之后移动或删除，不影响复制进去的文件；没有选择文件直接保存则会产生空配置。这里描述文件进入客户端的过程，不把目录里出现配置文件当作代理已经开启。

v2rayN 的界面说明给出 Ctrl+V 从剪贴板导入，支持明文与 BASE64。解析次序包括以 https 开头的地址作为新增订阅，再处理标准协议分享、SIP008、WireGuard、内部链接及若干自定义配置形式；不能解析时会提示错误。这份次序只对应该项目的解析流程，不是任意桌面客户端共享的输入承诺。

它还将自定义路由规则写为 JSON 数组，并将详细含义指向 Xray 文档。本地混合监听同时接收 SOCKS5 与 HTTP，与 Windows 系统代理只能自动配置 HTTP 的说明分别存在。把本地监听能力直接改写为系统菜单能配置同样项目，会混淆两个层面。

日志的主语也需要分清。v2rayN FAQ 将自身问题对应到 guiLogs 文件夹，将核心问题日志对应到主界面的信息栏；这些是官方说明里的位置，不是本文对某次失败作出的原因判断。读取日志入口与提出故障结论之间，仍需具体记录。

## FAQ

### 系统代理开了，为什么还要区分程序？

Verge 文档说这种接法依赖应用读取系统设置。该说明没有把全部程序都纳入同一覆盖承诺。

### TUN 和全局模式是同一个东西吗？

TUN 描述虚拟网络接口。全局模式描述所选出口，两者在 Verge 文档中属于不同概念。

### Verge 的默认栈到底是哪一个？

其文档写 GVisor，mihomo 英文页写 mips。本页保留两个来源的文字，不替实际安装版本选择答案。

### Windows 的 v2rayN 一定有 EXE 安装版吗？

指定发布资料列的是 ZIP 包，没有取得 EXE 安装包记录。不能把 FlClash 的 Windows 安装形式套到 v2rayN。

### 装扩展就表示电脑上的程序全部接入了吗？

现有页面只确认浏览器入口存在。整机作用范围的完整定义未取得，不能据此作这种结论。

### 免费版没有数据上限，就没有其他限制吗？

Proton 免费页另有同时设备数和随机国家分配说明。数据额度这一项没有替代其余使用条件。
